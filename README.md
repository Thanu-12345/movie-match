# 🎬 Movie Match

A hybrid movie recommendation system that recommends movies based on content similarity and user ratings.

## 🚀 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- TF-IDF
- Cosine Similarity

## ✨ Features

- Content-based movie recommendations
- Movie genre analysis
- Rating-based popularity analysis
- Interactive Streamlit application
- Similarity-based movie suggestions

## 📊 Dataset

MovieLens dataset containing movie titles, genres, and user ratings.

## ▶️ Run the Application

```bash
streamlit run app.py
